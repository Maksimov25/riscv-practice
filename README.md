**Группа:** М3О-121СВ-26

## Задания

| Файл | Задание |
|---|---|
| `task_a.asm` | Принимает целое число x и выводит 1, если оно равно номеру студента в списке (7), иначе 0 |
| `task_b.asm` | Принимает целое число x и выводит значения от min(x, y) до max(x, y) с шагом h, где y = 121 (номер группы), h = 7 (номер студента) |
| `task_c.asm` | Заполняет массив из 23 (16 + 7) целых чисел со стандартного ввода; чтение заканчивается после 23 значений или при вводе 0 |
